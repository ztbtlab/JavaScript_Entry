# 練習1: ボタンで文字色を変える

## 問題

画面には見出しとボタンがある。**ボタンを押したら、見出しの文字色が赤に変わる** ようにしてほしい。

編集するのは `main.js` だけ。HTML（`index.html`）は触らなくてよい。

## 完成イメージ

- 開いた直後: 黒い文字で「このタイトルの色を変えてみよう」と表示されている
- 「色を変える」ボタンを押す
- 見出しが**赤**に変わる
- （拡張チャレンジ）もう一度押すと黒に戻る

## ヒント

1. HTML の要素を JS で使うには `document.getElementById("id名")` で「取ってくる」必要がある。見出しの id は `title`、ボタンの id は `change-color`。
2. 「ボタンがクリックされたら何かをする」を予約するには `addEventListener("click", 関数)` を使う。第 2 引数は**関数名だけ**（カッコは付けない）。
3. 文字色を変える方法は、生徒用ノート `student-note.md` の「よく使う API」表にヒントがある。CSS の色指定と同じ書き方（例: `"red"`, `"black"`）で OK。

> いきなり答えを書かず、まず `console.log(title)` などを入れて要素がちゃんと取れているかを Console で確認するクセをつけよう。

## チェックポイント
