# 練習2: 距離センサー値を map で変換

## 問題

距離センサーで測った値（cm）の配列を、`map` を使って **まとめて mm（ミリメートル）に変換** する。
cm を mm にするには **10 倍** する（1 cm = 10 mm）。

```js
const distancesCm = [12, 8, 30, 5, 21];
// ↓ これを map で変換して
const distancesMm = [120, 80, 300, 50, 210];
```

編集するのは `main.js` だけ。結果は画面の枠と Console の両方に出す。

## 完成イメージ

- 画面の枠に `120, 80, 300, 50, 210 mm` と出る
- Console に元の配列（cm）と変換後の配列（mm）が両方出る

## ヒント

1. まず **1 個ぶんの変換ルール** を関数にする。`cmToMm(cm)` は `cm * 10` を `return` するだけ。
2. `map` は「配列を 1 個ずつ変換して、**新しい配列を返す**」メソッド。`distancesCm.map(cmToMm)` と書くと、`cmToMm` が各要素に対して呼ばれる。
3. `map` は **新しい配列を返す** ので、必ず変数で受け取る（`const distancesMm = distancesCm.map(cmToMm);`）。受け取らないと結果が消える。**元の配列 `distancesCm` は変わらない**。
4. 配列を「120, 80, 300」のように 1 行の文字列にするには `配列.join(", ")` を使う。画面表示はこれを使う。

> `map` の中に渡しているのは、練習1 で習った **関数**。`distancesCm.map((cm) => cm * 10)` のように、アロー関数をその場で書いても同じ。

## チェックポイント

- [ ] **動作**: 画面と Console に mm 変換後の配列が出る
- [ ] **map の理解**: 元の配列 `distancesCm`（cm）は変わらず、`map` が **新しい配列** を返している
- [ ] **個数**: 変換後も要素数は 5 個のまま（`map` は個数を変えない）
- [ ] **戻り値**: `cmToMm` が `return` で値を返している

## デバッグのコツ

- 画面に何も変わらないときは、`console.log(distancesMm);` を入れて、変換後の配列ができているか確認する。
- `undefined` の配列が出たら、`cmToMm` の `return` 忘れ。
- 「mm が変わらない」ときは、`map` の結果を変数で受け取り忘れている（`distancesCm.map(...)` だけで終わっていないか）。
