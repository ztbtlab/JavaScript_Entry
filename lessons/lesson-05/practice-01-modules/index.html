練習1: カウンターを 3 つのファイルに分ける

第4回で作ったカウンター（＋リセット）が、いまは main.js 1 つに全部入っている。 これを logic.js（計算担当）と ui.js（画面担当）に分けて、 分ける前とまったく同じ動きにするのが今日の練習。 動きが変わらないのが正解。

⚠️ Live Server で開くこと

import を使うページは、index.html をダブルクリックして開くと 動かない（アドレスが file:// になっている状態）。 VS Code で index.html を右クリック → Open with Live Server で開き、アドレスが http://127.0.0.1:5500/... になっていることを確認しよう。

進め方（一気に全部移さない。1 つ移して動かす → 次を移す）

  1. logic.js に increment を 1 つだけ移す → main.js から import して ＋1 が動くか確かめる （TODO 1・3）
  2. 動いたら decrement / reset も同じように移す
  3. 画面の書き換えを ui.js の showCount(value) に移す（TODO 2）
  4. 下の <script> に type="module" を足す（TODO 4）
