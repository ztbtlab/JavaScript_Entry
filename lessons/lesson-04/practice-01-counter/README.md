# 練習1: カウンター

## 問題

ボタンを押した回数を **プログラムに覚えさせて**、画面に表示する。

- `+1` を押すと数が 1 増える
- `-1` を押すと数が 1 減る
- 何回連続で押しても、続きから増減する（毎回 0 に戻らない）

編集するのは `main.js` だけ。

## 今日の 3 ステップ

```
① 状態を持つ            let count = 0;      ← すでに書いてある
② イベントで状態を変える   count = count + 1;
③ 画面を描き直す         showCount();
```

**② と ③ は別の仕事。** 「変数は変わったのに画面が変わらない」は、③ の呼び忘れ。

## 使う名前

| 種類 | 名前 | 役割 |
|------|------|------|
| 状態 | `count` | 今の数（`let count = 0;`） |
| 表示先 | `countLabel` | 数を出す `<span id="count">` |
| ボタン | `plusButton` | `<button id="plus">` +1 |
| ボタン | `minusButton` | `<button id="minus">` -1 |
| 関数 | `showCount()` | `count` を `countLabel` に映す |

## ヒント（番号は `main.js` の TODO と同じ）

## つまずきやすいところ

- **クリックのたびに 0 に戻る** → `let count = 0;` をイベントの関数の**中**に書いていないか。
  Arduino で `int count = 0;` を `loop()` の**中**に置いたときと同じ症状。関数の外に出す。
- **画面の文字を読んで計算している** → `countLabel.innerText + 1` は文字列がつながって `"01"` になる。
  **本物は変数 `count`、画面はそのコピー。**
- **`const count = 0;` にして代入エラー** → 書き換わる値は `let`。

## チェックポイント

- [ ] **動作**: `+1` で増え、`-1` で減る。連続クリックでも正しい
- [ ] **状態**: `let count = 0;` がイベント関数の外にある
- [ ] **表示更新**: 状態を変えた直後に必ず `showCount()` を呼んでいる
- [ ] **初期表示**: 読み込み時に `showCount()` を 1 回呼んでいる（最初の `-` が `0` に変わる）
- [ ] **画面から読み返していない**: 計算に使っているのは `count`（`innerText` ではない）
