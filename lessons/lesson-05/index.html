第5回: モジュール分割と PR

今日のゴールは 2 つ。1 つめは、1 つのファイルに全部書いていたコードを 役割ごとに別ファイルへ分けること（export と import）。 2 つめは、自分でブランチ（枝）を作って PR（プルリクエスト）を出すこと。 新しい文法は少なめで、手順を自分の手で 1 周させるのが今日の主役。

今日のキーワード

  • モジュール（module）
  • export（貸し出す）
  • import（借りてくる）
  • type="module"
  • logic.js（計算担当）
  • ui.js（画面担当）
  • main.js（司令塔）
  • Live Server
  • ブランチ（枝）
  • PR（プルリクエスト）
  • レビュー
  • マージ

⚠️ 今日は「ダブルクリックで開く」と動かない

import を使ったページは、index.html をダブルクリックして開くと エラーになる（アドレスが file:// で始まる状態）。 必ず VS Code で index.html を右クリック → Open with Live Server で開くこと。 アドレスが http://127.0.0.1:5500/... になっていれば OK。

授業スライド（講師用）

第5回 スライド（Reveal.js / ブラウザ全画面） — 授業進行用。矢印キー／スペースで進む、S キーでスピーカーノート表示。

練習問題

  1. 練習1: カウンターを 3 つのファイルに分ける — logic.js / ui.js / main.js と export / import
  2. 練習2: ブランチを切って PR を出す — git switch -c → commit → push → PR → レビュー → マージ（今日の本命）
  3. 練習3: 三択クイズをモジュール分割で作る 発展 / 宿題 — questions / judge / showQuestion / showResult

※ 練習3 は発展課題。授業内は練習1・2を進め、早く終わった人だけ練習3に進む。 練習3は全員、宿題として家で取り組み、自分で切ったブランチから PR で提出する。

今日からの提出のしかた（第2〜4回との違い）

  • 第2〜4回: 講師が用意した answer/lesson-0X-YY-* ブランチに提出していた
  • 第5回から: 自分で feature/... ブランチを作って、PR で提出する
  • answer/* ブランチと各練習の answer/ フォルダは 講師の模範解答置き場。見てもよいが、そこに提出はしない
  • ⚠️ main ブランチと answer/* ブランチは消さないこと

このリポジトリは Public（世界中から見える）。 コミットメッセージ・PR のタイトル・説明に、 本名・学校名・住所などは書かない。

うまく動かないときは（この順で確認）

  1. アドレス欄が http://127.0.0.1:... になっているか （file:// なら Live Server で開き直す）
  2. index.html の <script> に type="module" が付いているか
  3. F12（Mac は ⌘ + Option + I）で DevTools を開き、 Console のエラー 1 行目を読む
  4. import { 名前 } from "./logic.js"; の 波カッコ・./・.js の 3 つが揃っているか
  5. 借りてくる側だけでなく、貸し出す側に export が付いているか
