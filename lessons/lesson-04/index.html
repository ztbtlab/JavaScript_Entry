第4回: 状態を持つ UI

今日のゴールは「プログラムに今どうなっているかを覚えさせる」こと。 この“覚えている値”を 状態（じょうたい / state） と呼ぶ。 ボタンを押すたびに数が増えるカウンター、押すたびに開いたり閉じたりするパネル、 入力をチェックするフォーム — どれも同じ 1 つの型でできている。

今日ずっと使う 3 ステップ

  1. 状態を持つ — let count = 0;（変わる値なので let）
  2. イベントで状態を変える — count = count + 1;
  3. 画面を描き直す — showCount();

② と ③ は別の仕事。「変数は変わったのに画面が変わらない」は、たいてい ③ の呼び忘れ。

今日のキーワード

  • 状態（state）
  • let（書き換わる変数）
  • 表示更新関数
  • innerText
  • classList.add / remove / toggle
  • 真偽値の反転（!）
  • input の .value
  • trim()
  • 検証（バリデーション）
  • 早めに return

授業スライド（講師用）

第4回 スライド（Reveal.js / ブラウザ全画面） — 授業進行用。矢印キー／スペースで進む、S キーでスピーカーノート表示。

練習問題

  1. 練習1: カウンター — count を状態として持ち、showCount() で画面に映す
  2. 練習2: トグル（開く / 閉じる） — isOpen と classList.toggle で表示 / 非表示を切り替える
  3. 練習3: センサー登録フォーム 今日の総合問題 — checkInput(text) で空入力をはじき、registeredCount を増やす

※ 今日は練習3まで授業内で取り組む。時間内に終わらなかった人は、 続きを家でやって同じブランチで提出する。 全員共通の宿題は練習1 のカウンターに「リセット」と「5 ずつ増やす」を足す拡張課題。

うまく動かないときは

  • ブラウザで F12（または ⌘ + Option + I）で DevTools を開き、Console タブを見る
  • 数が増えない → console.log(count) で確認。値が変わっているなら画面更新の呼び忘れ
  • クリックのたびに 0 に戻る → let count = 0; をイベントの関数の中に書いていないか（Arduino の loop() の中に置いたのと同じ状態）
  • classList.toggle に渡すのは "hidden"。CSS の . は付けない
  • 入力欄の文字が取れない → <input> だけは innerText ではなく .value
  • 赤い文字のエラーはそのまま読む（英語でも OK。分からない単語だけ調べる）
