# 練習3: センサー登録フォーム

## 問題

センサー名を入力して「登録」を押すと、**登録済みの件数が増える**フォームを作る。
ただし、入力をそのまま信じてはいけない。空っぽなら **エラーを出して弾く**。

**今日の総合問題。** 状態（練習1）＋ クラスの付け外し（練習2）＋ 検証（バリデーション）の合わせ技。

編集するのは `main.js` だけ。`style.css` に `.error`（枠が赤くなる名札）は用意してある。

## 完成条件（3 つとも満たすこと）

1. 空のまま「登録」を押すと **エラー文言が出て、件数は増えない**
2. スペースだけ打って押しても **エラーになる**
3. 文字を入れて押すと **件数が 1 増え、エラーが消え、入力欄が空に戻る**

## 今日の言葉: 検証（バリデーション）

**検証 = 入力が使える形か確かめること。**

```js
const text = sensorInput.value.trim(); // ① 入力欄の値を取る
if (text === "") {                     // ② 空かどうか調べる
  // ダメだった
}
```

- `<p>` や `<span>` は `innerText`、**`<input>` だけは `.value`**。ここが第2回からの差分。
- `.value` は **必ず文字列**。数として計算したいときは `Number(...)` を通す。
- **`trim()`（トリム）= 前後の空白を取り除く。** `"   "` は `""` ではないので、trim しないとすり抜ける。
- **エラーは「出す」＋「消す」がセット。** OK のときに消し忘れると、直したのに赤いまま残る。

## 使う名前

| 種類 | 名前 | 役割 |
|------|------|------|
| 状態 | `registeredCount` | 登録できた件数（`let registeredCount = 0;`） |
| 入力欄 | `sensorInput` | `<input id="sensorInput">` |
| ボタン | `submitButton` | `<button id="submitButton">` 登録 |
| エラー表示 | `errorMessage` | `<p id="errorMessage">` |
| 件数表示 | `countLabel` | `<span id="count">`（練習1 と同じ名前で揃えてある） |
| 関数 | `checkInput(text)` | 空なら `false` + エラー表示、OK なら `true` + エラー消去 |
| 関数 | `showCount()` | `registeredCount` を `countLabel` に映す |
| CSS クラス | `error` | 入力欄の枠を赤くする |

## ヒント（番号は `main.js` の TODO と同じ）

1. `showCount()` は練習1 とまったく同じ形。`registeredCount` を `countLabel` に映す。（TODO 1）

   エラー文言は「出す」だけでなく、OK のとき「消す」までがセット。（TODO 2）

5. 最初の表示のために `showCount()` を 1 回呼ぶ。このページは最初 `-` と出ているので、

## つまずきやすいところ

- **`sensorInput.innerText` で取ろうとする** → 入力欄だけは `.value`。打った文字は `innerText` には入らない。
- **`if (text = "")` と `=` ひとつで書く** → `=` は「入れる」、`===` は「比べる」。ここは比べたい。
- **エラーが消えない** → OK のときに `errorMessage.innerText = "";` を書いたか。
- **スペースだけが通ってしまう** → スペースも文字。`trim()` してから比べる。
