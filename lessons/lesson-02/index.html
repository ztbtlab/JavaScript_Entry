授業スライド（講師用）

第2回 スライド（Reveal.js / ブラウザ全画面） — 授業進行用。矢印キー／スペースで進む、S キーでスピーカーノート表示。

練習問題

  1. 練習1: ボタンで文字色を変える — getElementById と addEventListener("click", ...)
  2. 練習2: 入力を大文字に変換 — <input>.value と "input" イベント
  3. 練習3: ラジオ選択で挨拶切替 — querySelectorAll と if/else

うまく動かないときは

  • ブラウザで F12（または ⌘ + Option + I）で DevTools を開き、Console タブを見る
  • 赤い文字のエラーをそのまま読む（英語でも OK。分からない単語だけ調べる）
  • あやしい変数は console.log(変数名) で中身を見る
  • HTML の id と JS の getElementById("…") の文字が完全に一致しているか確認
