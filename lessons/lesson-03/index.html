第3回: 関数で整理する

今日のゴールは「処理を関数にまとめて読みやすくする」ことと、 「配列を map でまとめて変換し、filter で絞り込む」こと。 結果はおもに DevTools の Console（ブラウザの開発者ツール）で確かめる。 下の練習を上から順にやっていこう。

今日のキーワード

関数（function） 引数 戻り値（return） アロー関数（=>） 配列 map filter reduce（名前だけ） console.log DevTools Console

練習問題

  1. 練習1: 関数で整理する — calcTotal と applyTax（引数・戻り値・アロー関数）
  2. 練習2: 距離センサー値を map で変換 — cmToMm と distancesCm.map(...)
  3. 練習3: 気温配列を filter で絞り込む 発展 / 宿題 — isHot と temps.filter(...)

※ 練習3 は発展課題。授業内は練習1・2を進め、 早く終わった人だけ練習3に進む。練習3は全員、宿題として家でも取り組む。

うまく動かないときは

  • ブラウザで F12（または ⌘ + Option + I）で DevTools を開き、Console タブを見る
  • 練習1 は画面に何も出ない。結果は Console に出るので、必ず Console を開く
  • undefined が出たら、関数に return（戻り値の出口）を書き忘れている合図
  • 赤い文字のエラーをそのまま読む（英語でも OK。分からない単語だけ調べる）
  • あやしい変数は console.log(変数名) で中身を見る
