____ クイズ

三択のクイズ。ボタンを選ぶと ◯ か ✗ が出て、「次の問題へ」で進む。

（ここに問題文が出る）

作るファイルは 4 つ

  • quiz-data.js … 問題のデータ（questions）
  • logic.js … 正解かどうかを判定（judge）。document は書かない
  • ui.js … 画面に出す（showQuestion / showResult）
  • main.js … 状態を持って 3 つをつなぐ司令塔

くわしい手順は README.md を見ること。

⚠️ Live Server で開くこと。 ダブルクリック（file://）では import が動かない。
⚠️ 問題文に、個人が特定できることを書かない。 このリポジトリは Public（世界中から読める）。
