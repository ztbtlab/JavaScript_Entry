練習2: トグル（開く / 閉じる）

ボタンを押すたびに、説明パネルが消えたり出たりするようにしよう。 見た目を変えるのは CSS の名札（クラス）、覚えておくのは状態 isOpen。

センサーのつなぎ方

温度センサーは、信号線をアナログ入力ピンにつなぐ。 読み取った値は 0〜1023 の数字で返ってくるので、温度に直す計算が必要になる。

— こういう「長いけれど、いつも見たいわけではない説明」を、 必要なときだけ開く形にするのがトグル。

完成の目安

  • ボタンを押すとパネルが消え、もう一度押すと出る
  • ボタンの文字が「閉じる」↔「開く」で入れ替わる
  • パネルの表示とボタンの文字がずれない

編集するのは main.js だけ。style.css に .hidden は用意してある。
