# 練習2: 入力を大文字に変換

## 問題

入力欄に文字を打つと、**そのたびに**下の「結果:」に大文字バージョンが表示されるようにする。

編集するのは `main.js` だけ。

## 完成イメージ

- 入力欄に `hello` と打つ
- 打つごとに（1 文字ずつ）結果欄が `H` → `HE` → `HEL` → ... → `HELLO` と更新される
- 全部消したら結果欄も空になる（または「（まだ入力されていません）」と出る）

## ヒント

1. `<input>` の中の文字は `要素.innerText` **ではなく** `要素.value` で取る。これは 1 回だけ覚えてしまうと一生使う。
2. 大文字に変換するのは JS の文字列メソッド。`"abc".toUpperCase()` で `"ABC"` になる。
3. 「クリックされたら」ではなく「入力されたら」反応させたいので、`addEventListener` の第 1 引数は `"click"` ではなく `"input"`。

## チェックポイント

- [ ] **動作**: 入力するたびに（リアルタイムに）結果欄に大文字が出る
- [ ] **コード構造**: 1 つの関数（例: `handleInput`）で「value を読む → 大文字にする → 表示欄に入れる」の流れが書かれている
- [ ] **命名**: 変数名が `source` / `output` など役割が分かる名前になっている

## 動かし方

VS Code の Live Server で `index.html` を開く。
DevTools の Console を開いた状態で作業すること。エラーはそこに出る。

## デバッグのコツ

- 何も出ないときは、`console.log("value:", source.value);` を入れて Console を見る
- 「`null` is not …」系のエラー → `getElementById` の id を書き間違えている
