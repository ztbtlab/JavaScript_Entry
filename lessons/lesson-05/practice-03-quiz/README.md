**この練習は発展課題＝宿題。** 授業中は練習1・練習2 を先に進め、
早く終わった人だけ着手してよい。全員、家で仕上げて **PR で提出**する。

## 問題

三択クイズの小ツールを作る。ただの 1 ファイルではなく、
**練習1 でやったモジュール分割の形（4 ファイル）で作る**のがこの課題の主眼。

| ファイル | 中身 | 状態 |
|----------|------|------|
| `quiz-data.js` | `export const questions = [...]`（問題文・三択・正解番号の配列。3 問くらい） | 1 問だけ例が入っている。あと 2 問足す |
| `logic.js` | `export function judge(question, selectedIndex)` — 選んだ番号が正解かを `true` / `false` で返す | 穴あき |
| `ui.js` | `export function showQuestion(question)` / `export function showResult(isCorrect)` | 穴あき（部品の取得だけ書いてある） |
| `main.js` | 状態（いま何問目か・何問正解か）を持ち、上の 3 つをつないで動かす | 穴あき |
| `index.html` | 画面の骨組み。`<script type="module">` も付いている | 題名（`____ クイズ`）だけ書き換える |
| `style.css` | 見た目 | 触らなくてよい |

**完成条件**: 3 問のクイズが動き、選ぶと ◯ / ✗ が出て、「次の問題へ」で次の問題に進む。
ここまでできたら宿題は合格。

> 最後まで進んだときの**点数の表示（`showScore`）は発展**。作らなくてもよい
> （その場合、最後の問題が出たままになる）。余裕がある人は下の「余裕があれば」で作る。

## ヒント

1. **`judge` は if を使わずに 1 行で書ける。**
   「同じかどうか」を `===` で比べた結果が、そのまま `true` / `false` になる。
2. **`question.choices` は配列**。`question.choices[0]` が 1 つめの選択肢。
   `answerIndex` も **0 から数える**（1 つめ＝ 0）。
3. **`showQuestion` は 3 つのボタンの文字を入れかえる**。
   `for (let i = 0; i < choiceButtons.length; i++)` で回すと 3 行書かずに済む。
4. **`showResult` は `if (isCorrect) { ... } else { ... }`** で出す文字を変えるだけ。
5. **`main.js` の `i`** は「何番のボタンが押されたか」。それをそのまま `judge` に渡す。
6. **問題が残っているかの判定**は `currentIndex < questions.length`。
   `questions.length` は問題の数。
7. `logic.js` に `document` を書いてしまったら、分け方を間違えた合図。画面の仕事は `ui.js` へ。

> 答えそのものは書いていない。詰まったら、まず生徒用ノートの
> 「2. `export` と `import`」を読み返すこと。

## 提出方法（今日習った手順で）

⚠️ **今回から `answer/*` ブランチには提出しない。** 自分でブランチを作って PR を出す。

`xx` は**講師が配る自分の記号**（練習2 と同じもの）に置き換える。

## 用語メモ

- **配列**: 値をまとめた箱。`[10, 20, 30]`。番号は **0 から**数える（第3回）。
- **オブジェクト**: 名前を付けて値をまとめた箱。`{ text: "...", answerIndex: 0 }` の形。
  中身を取り出すときは `question.text` のように `.` でつなぐ。
- **`true` / `false`（真偽値）**: 「はい」「いいえ」を表す値（第3回の `filter` で使った）。
